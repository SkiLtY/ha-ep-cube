## 🏷️ EP Cube Integration v1.6.4 — name your solar strings

> **TL;DR** — you can now give each solar string a name in the Configure screen, for example "East roof" ([#17](https://github.com/SkiLtY/ha-ep-cube/issues/17)). Its power, voltage and current sensors use the name instead of "PV1". Nothing else changes.

### ✨ New

- **Friendly names for the PV strings.** Settings → Devices & services → EP Cube → Configure has four optional fields, one per string. Leave one blank to keep "PV1" to "PV4". Only the display name changes: entity IDs, history, the Energy dashboard and your automations are untouched.
- Translated into German, Italian and Dutch.

### 📦 Upgrading

Update via HACS and restart Home Assistant, then open Configure to name your strings.
